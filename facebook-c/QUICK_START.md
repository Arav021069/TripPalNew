# Quick Start Guide - TripPal with Gemini AI

## 🚀 Get Started in 3 Steps

### 1. Install Dependencies
```bash
cd facebook-c
npm install
```

### 2. Setup Gemini AI
```bash
npm run setup-gemini
```
Follow the prompts to enter your Gemini API key.

**OR** manually create a `.env` file:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Start the Application
```bash
npm run dev
```

## 🎯 New AI Features

### 🤖 AI Assistant
- Click "AI Assistant" on the home page
- Ask any travel-related questions
- Get personalized recommendations

### 📋 AI Travel Planner
- Click "AI Travel Planner" on the home page
- Enter destination, duration, interests
- Generate custom itineraries

### 🔍 Smart Search
- Go to Explore page
- Type in search box for AI suggestions
- Get intelligent recommendations

### 🏥 Medical Assistant
- Go to Medical Services page
- Describe symptoms for AI guidance
- Get first aid and medical advice

## 🔑 Getting Your API Key

1. Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Sign in with Google account
3. Create new API key
4. Copy and paste into setup

## 🆘 Troubleshooting

**No AI responses?**
- Check your API key in `.env` file
- Ensure you have internet connection
- Check browser console for errors

**Setup issues?**
- Make sure you're in the `facebook-c` directory
- Run `npm install` first
- Check Node.js version (14+ required)
